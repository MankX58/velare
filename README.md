# Velare

Proyecto web de Velare.

## Descripción

Velare es una tienda online orientada a ofrecer una experiencia de compra clara, rápida y fácil de usar.

## Estado

Proyecto en desarrollo.

## Requisitos

- Git
- Node.js y npm, cuando se configure el entorno de desarrollo

## Configuración

1. Clona el repositorio:

   ```bash
   git clone https://github.com/MankX58/velare.git
   cd velare-shop
   ```

2. Crea un archivo `.env.local` a partir de `.env.example` cuando este último esté disponible.
3. Completa las variables de entorno necesarias para el proyecto.

> Los archivos `.env*` se mantienen fuera del control de versiones para evitar publicar credenciales.
